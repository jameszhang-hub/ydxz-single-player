# 魔兽独立重做规格

更新日期：2026-07-20。实现证据来自
`source-assets/user-screenshots/original-audit/ydxz-original-audit-2026-07-17.m4v` 与
`source-assets/live-capture/beast-reference-2026-07-19.mov`。
本文件是本轮魔兽实现的唯一规则基线。未在录屏、游戏内问号或官网公示中确认的内容，
不得在界面中标成原作规则。

## 1. 页面结构

### 1.1 魔兽空间（105~134 秒）

- 进入魔兽后直接打开魔兽空间，不经过自创总览页。
- 竖屏全屏场景从上到下依次为：资源条、出战祭坛、`助战 3/3`、`图鉴`、
  4x4 共 16 个兽栏格、绿色/蓝色/黄色（史诗）三颗魔兽蛋、右侧功能按钮和返回按钮。
- 观察账号开放前 8 格，后 8 格显示锁。锁位条件尚未取得，单机版保留进度解锁，
  但不宣称为原作等级表。
- 点击祭坛魔兽进入详情。点击助战进入三助战位。点击图鉴进入四系图鉴。
- 点击蛋直接在空格孵化；没有空格时必须给出明确反馈，不能静默扣蛋。
- 绿色蛋每 6 小时免费获得 1 枚，库存达到上限后暂停。问号原文为“超过 6 颗时
  不再免费获得”，边界暂按最多 6 枚实现并在代码中标为待核实。

### 1.2 魔兽详情（170~192 秒）

- 使用羊皮纸面板，底部固定四页签：`魔兽详情`、`技能洗炼`、`魔兽吞噬`、`魔兽升阶`。
- 详情展示魔兽立绘、品质、等级、当前经验/升级需求、每级四项成长、对主角加成、
  四个战斗技能位和四个被动技能位。
- 技能洗炼左右对照当前技能和洗炼结果；一次重洗四条，费用画面样例为 80000 金币；
  结果出现后可保留、替换或直接继续洗炼。
- 洗炼词条类型权重、初/中/高品质率以官网公示为准；洗炼只替换词条内容，四个槽位
  已提升的被动等级必须保留。随机升级一条被动消耗 8 魔晶，单槽最高 20 级。
- 魔兽吞噬与经验精灵喂养是两个不同系统。吞噬页有三个成长概率圆盘、吞噬等级、
  五个独立材料位、`一键选择`、`吞噬`。吞噬可选择兽栏里的其他普通魔兽，也可直接
  使用魔兽精华；经验精灵仍只提升普通等级，不能混入吞噬等级。
- 升阶条件为魔兽等级达到 50 级且吞噬等级达到指定等级。录屏样例为吞噬等级 3，
  2 阶升 3 阶后技能伤害 151% -> 156%、攻击加成 25% -> 28.5%。

### 1.3 超凡觉醒与强化（198~205 秒）

- 魔兽达到超凡品质后，进入独立的觉醒场景继续提升星级或品质。
- 觉醒 100% 成功；觉醒后继承主魔兽被动技能。
- 达到超凡 1 星后开启强化，并且必须强化至满级才能继续觉醒。强化有概率成功，
  成功时强化等级 +1；失败时有概率降低 1~3 级。录像强化示意的满级为 `+10`。
- 强化可额外添加增率道具和失败保护道具。
- 失败降低等级后可用回溯恢复到本次强化前；回溯等级越高，消耗越高。
- 超凡只有初始、1 星、2 星、3 星四个形态；3 星完成强化条件后可 100% 觉醒为
  对应璀璨魔兽，不存在 4 星或 5 星超凡。璀璨之后的继续成长尚无录屏证据。
- 觉醒消耗兽栏中的其他基础超凡魔兽。录像显示最多三个材料位，但各阶段精确数量尚未
  取得；单机版暂用 `1/2/3/3`，不得写成官网或原作确认值。
- 觉醒后继承普通等级、吞噬等级、升阶和四条被动；升阶与觉醒是并行系统，互不覆盖。
- 觉醒和强化必须作为两个按钮、两套状态和两套资源处理，禁止再把随机强化概率写到
  100% 觉醒按钮上。

## 2. 棋盘状态机

兽栏每格只允许三种状态：`empty`、`beast`、`exp_spirit`。每格永远只放一个实体，
不按物种或经验精灵类型自动堆叠。格位另有 `unlocked/locked`，魔兽实体另有防误合成
的 `protected` 状态。出战祭坛是独立格位：拖上去后实体离开 16 格，必须先拖回空格
才能参与合成或作为材料。

### 2.1 孵化

1. 消耗所点蛋 1 枚。
2. 从该蛋已配置的池中抽出 1 只魔兽。
3. 放入第一个已解锁空格。
4. 写入图鉴发现状态并更新主角永久图鉴加成。
5. 没有空格时步骤 1~4 均不发生。

黄色蛋固定产出史诗品质。稀有、传说、完美、超凡特殊蛋按官网公示物种与概率；
普通绿/蓝/黄色蛋内部物种权重与钻石售价属于单机配置，不得标成官方概率。

### 2.2 拖拽合成

- 只有两个同品质 `beast` 可以拖到一起合成，不要求同名。
- 被保护、出战或助战魔兽不得被一键合成或手动合成消耗；必须先撤下或解除保护。
- 目标品质与官网/游戏内公示成功率：

| 结果品质 | 成功率 |
| --- | ---: |
| 精良 | 90% |
| 稀有 | 80% |
| 史诗 | 60% |
| 传说 | 30% |
| 完美 | 20% |
| 超凡 | 10% |

- 普通合成成功：消耗两只投入魔兽，在目标格生成下一品质随机魔兽。
- 普通合成失败：消耗两只投入魔兽，在目标格生成同品质经验精灵 1 个。
- 完美合成超凡失败：同时在目标格生成完美经验精灵 1 个并获得超凡魔兽碎片 1 个；
  5 片可随机合成 1 只基础超凡魔兽。
- 优秀至完美品质每次合成都独立判定魔晶掉落，依次为 0.04%、0.18%、1%、5.6%、
  48%、90%。成功或失败都可触发。
- 超凡和璀璨都不参与普通棋盘合成；超凡升星与升璀璨统一从详情进入觉醒页。

### 2.3 经验精灵

- 经验精灵是合成失败后出现在兽栏格内的独立魔兽实体，每只占一个格子。
- 经验精灵可以出战、助战、进入详情和培养，也可以作为接收经验的一方。
- 把一只经验精灵拖到任意品质、任意物种的魔兽上会消耗该精灵并增加目标普通等级经验；
  经验精灵拖到另一只经验精灵同样执行喂养升级，不是普通品质合成。
- 不同品质经验精灵提供不同经验：优秀 600，此后每升一品质翻倍，完美为 19200。
- 经验精灵不能进入普通合成或“魔兽吞噬”五格。一键整理只压缩空格，一键合成只处理
  可安全消耗的普通同品质魔兽，不自动消费经验精灵。

## 3. 图鉴

- 根页四系进度固定为自然系 13、元素系 17、暗影系 11、传说系 7，总计 48。
- 每系按优秀、精良、稀有、史诗、传说、完美、超凡、璀璨纵向排列，每行四格；
  行内不足四项的问号只是排版填充，不计入分母。
- 视频确认的每系各品质实际数量：
  - 自然 `[1,1,2,2,1,1,4,1]`
  - 元素 `[2,2,2,2,2,2,4,1]`
  - 暗影 `[0,0,2,2,1,1,4,1]`
  - 传说 `[0,0,0,0,1,1,4,1]`
- 48 个录像位置的 ID、正式名称、品质、派系、图位与原始帧已全部锁定在
  `source-assets/live-capture/beast-atlas-map.tsv`。自然系 13、元素系 17、暗影系 11、
  传说系 7 均不得再用占位名或复用图片。
- 合成图谱中的四组材料只是录像式示例。实际规则只校验两只投入魔兽品质相同，允许跨物种、
  跨阵营合成，成功结果从下一品质完整候选池随机产生。
- 单卡详情至少包含基础加成、图鉴加成、四战斗技能、合成图谱、收集奖励和
  `初阶/满阶`切换。未在公示或录屏中确认的数值必须标成单机配置，不得伪装成原作值。
- 图鉴加成必须进入主角属性和战力计算，发现新图鉴时给出战力变化回执。

## 4. 单机可玩性补充

以下不是原作录屏数据，而是为单机闭环补充的明确规则：

- 保留一键孵化、一键安全合成、一键整理；所有批量行为先保护出战、助战和手动锁定项。
- 提供无限模拟购买三类蛋和培养材料，不触发真实支付。
- 吞噬可消耗兽栏中的其他普通魔兽或魔兽精华，但不能用经验精灵替代。
- 每次孵化、合成、喂养、吞噬、升阶、洗炼、觉醒后都显示主人总战力增量；没有增量时
  明确说明该动作只改变库存或概率准备状态。
- 所有看起来可点击的祭坛、助战、图鉴、蛋、右侧按钮、格子实体、四详情页签、问号、
  材料格和主要按钮都必须有响应。

## 5. 验收路径

1. 390x844 和 430x932 视口中主屏首屏完整看到祭坛、16 格和三颗蛋，无横向滚动。
2. 绿蛋孵化后新增魔兽；满格不扣蛋。
3. 拖动两只不同物种同品质魔兽可合成；不同品质不触发。
4. 强制失败后生成一只独立经验精灵；每只占一格；拖到任意魔兽后只消耗这一只并升级。
5. 经验精灵拖到另一经验精灵可提升目标普通等级；一键合成不得消费经验精灵。
6. 超凡不能在兽栏合成；觉醒页消耗真实的其他超凡，依次得到 1/2/3 星，再转对应璀璨。
7. 点击任意魔兽可进入四页培养，四页签和每个主按钮均有有效状态变化或明确禁用原因。
8. 吞噬可消耗其他魔兽或精华；经验精灵不能进入吞噬材料位。
9. 超凡觉醒为 100%；1 星后强化 +10 才能继续；强化概率、失败掉级、保护和回溯独立可测试。
10. 四系图鉴总数为 48，行数和占位正确，发现项目实际改变主角属性和战力。
11. 完整走一遍后刷新页面，棋盘、出战独立格、培养、图鉴和资源全部从存档恢复。
12. 黄色蛋只能新增史诗品质实体；紫色稀有蛋只能新增稀有品质实体。
13. 图鉴 48 个实体的名称顺序与 CSS 图位必须和 `beast-atlas-map.tsv` 完全一致。
14. 洗炼前后四个被动槽等级不变；升阶前后觉醒星级不变；觉醒前后升阶等级不变。
15. 任何界面和文案都不得出现 4 星、5 星超凡，也不得要求所谓“4 星以上超凡”材料。
